## Инструкции по запуску

### Быстрый старт (рекомендуется)
1. Откройте файл test.html в браузере
2. Приложение готово к использованию!

### Запуск Vue приложения
1. npm install
2. npm run dev
3. Откройте http://localhost:3000

### Docker
docker-compose up --build

## Функциональность
- Поиск документов с debounce
- Предпросмотр документов
- Скачивание в .txt формате
- Удаление (только с изображениями)
- Адаптивный дизайн
